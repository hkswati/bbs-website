End-to-end installation, commissioning, and integration of DWDM optical transport systems and enterprise-grade IP switches — for telecoms operators, ISPs, and large-scale network deployments across KSA.

## DWDM Systems

We handle the full DWDM deployment lifecycle, from equipment staging and rack integration through to optical channel commissioning and live network cutover.

- DWDM chassis installation, racking, and cabling (line-side and client-side)
- Transponder, amplifier, and ROADM configuration
- Optical power budget verification and OSNR testing
- Channel commissioning and end-to-end wavelength turn-up
- Integration with existing OLS and ROADM networks
- EMS/NMS integration and alarm verification
- Cutover planning and execution with minimal service disruption
- Post-commissioning documentation and as-built records

## IP Switch Installation & Commissioning

- Rack mounting, power, and grounding to site standards
- Initial configuration from supplied templates or from scratch
- VLAN, STP, LACP, and routing protocol setup (OSPF, BGP, IS-IS)
- Interface testing and traffic verification
- Integration into existing network management platforms
- Acceptance testing against customer specifications
- Handover documentation and configuration backups
