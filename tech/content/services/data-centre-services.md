Full data centre and server room build-out — from rack installation and structured cabling through to server commissioning and documented handover. We work in new fit-outs and live brownfield environments across KSA.

## Rack Installation & Cabling

- Rack and cabinet installation, levelling, and securing
- PDU installation and power distribution (single and dual feed)
- Structured cabling — Cat6/6A patch panel termination, labelling, and testing
- Fibre patching and cable management within the rack
- Cable containment, tray routing, and overhead or underfloor dressing
- Ground bonding and earthing to site standards
- Cable schedule documentation and rack elevation diagrams

## Server Installation & Commissioning

- Physical server installation, racking, and cable dressing
- RAID, BIOS, and out-of-band management configuration (iDRAC, iLO, BMC)
- OS installation — Windows Server and Linux distributions (RHEL, Ubuntu, Rocky)
- Network configuration: hostname, IP assignment, VLAN tagging
- Firmware and driver updates to current stable release
- Burn-in and acceptance testing
- Full handover documentation — rack diagrams, cabling schedules, and configuration records

## Environments

- New data centre fit-outs
- Server room expansions and upgrades
- Colocation cage build-outs
- Enterprise on-premises infrastructure rollouts
- Disaster recovery site deployments
