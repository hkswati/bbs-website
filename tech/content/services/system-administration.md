We manage your server infrastructure end-to-end — from initial setup to ongoing patching, backup, and remote support.

## What we deliver

- Linux server setup and hardening — Ubuntu, Debian, Rocky Linux, AlmaLinux, CentOS Stream, and RHEL
- Windows Server setup and hardening
- Active Directory and Samba AD with Arabic display name support
- Remote helpdesk via MeshCentral — self-hosted inside KSA so your data never leaves the Kingdom
- Backup and recovery using Duplicati or UrBackup, with recovery testing included
- Automated patch management via Ansible
- Server health monitoring and alerting

## KSA relevance

PDPL requires that personal data of Saudi residents stays within KSA. Many commercial remote support tools (TeamViewer, AnyDesk) route data through overseas servers. MeshCentral deployed inside KSA keeps all session data within Saudi borders — a meaningful compliance difference.
